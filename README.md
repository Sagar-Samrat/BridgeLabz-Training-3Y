## 🛠 Tech Stack & Tools

During this program, we work with a modern tech stack and essential development tools:

- **Languages:** HTML5, CSS3, JavaScript (ES6+)
- **Runtime Environment:** Node.js
- **Version Control:** Git & GitHub
- **IDE:** Visual Studio Code (VS Code) with extensions like *Live Server*, *Prettier*, and *GitLens*
- **Browsers & Engines:** Google Chrome (Blink), Mozilla Firefox (Gecko), Safari (WebKit)

---

## 📝 Key Topics Mastered So Far

### 1. Web Architecture
- **Client-Server Model:** Understanding how browsers request resources and how servers process and respond with HTML, CSS, JavaScript, and other files.
- **Rendering Engines:** Understanding rendering engine differences (Blink, Gecko, WebKit) across different browsers.
- **Static vs. Dynamic Websites:** Distinguishing between static content-driven sites and dynamic database-driven applications.

### 2. Development Roles
- **Frontend Developer:** Building visual elements and interactive layouts.
- **Backend Developer:** Designing servers, databases, business logic, APIs, and authentication flow.
- **Full-Stack Developer:** Connecting client interfaces with server-side logic and databases to build complete web applications.

## 🚀 How to Run the Projects Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/sudhanshu09090/BridgeLabz-Training-3Y.git
   ```
2. **Navigate to the Project Directory:**
   ```bash
   cd BridgeLabz-Training-3Y
   ```
3. **Open in VS Code:**
   ```bash
   code .
   ```
4. **Run via Live Server:**
   - Install the **Live Server** extension in VS Code.
   - Open any HTML file (e.g., `index.html`).
   - Click **Go Live** at the bottom-right corner of VS Code to launch the project locally.
