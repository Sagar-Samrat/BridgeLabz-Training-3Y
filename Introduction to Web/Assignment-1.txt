1. Difference between Frontend, Backend, and Full-Stack Development
----------------------------------------------------------

Frontend Development:
Frontend is the part of a website that users can see and interact with. It focuses on designing the user interface (UI) and user experience (UX).

Technologies:
- HTML
- CSS
- JavaScript

Real-World Example:
On Amazon, the homepage, search bar, product images, and buttons are all part of the frontend.

Backend Development:
Backend is the server-side part of a website. It handles business logic, authentication, databases, and APIs.

Technologies:
- Java
- Python
- Node.js
- PHP
- MySQL
- MongoDB

Real-World Example:
When a user logs into Amazon, the backend verifies the username and password from the database.

Full-Stack Development:
A Full-Stack Developer works on both frontend and backend to build complete web applications.

Technologies:
- HTML
- CSS
- JavaScript
- Java/Python/Node.js
- Database

Real-World Example:
A developer building the complete Amazon shopping website from user interface to database.

Explanation:

3. The server sends the response back to the browser.

3. How a Browser Requests and Displays a Web Page
----------------------------------------------------------

Step 1: The user enters a website URL.
Step 2: The browser sends an HTTP request to the web server.
Step 3: The server receives and processes the request.
Step 4: The server returns HTML, CSS, JavaScript, and images.
Step 5: The browser downloads these files.
Step 6: The browser renders and displays the webpage.

5. What is a Web Server?
----------------------------------------------------------

A web server is software or hardware that receives requests from web browsers and sends web pages or other resources back to users over the Internet.

Examples of Web Servers:
- Apache HTTP Server
- Nginx
- Microsoft IIS
- LiteSpeed
- Apache Tomcat

8. Difference between Static and Dynamic Websites
----------------------------------------------------------

Static Website:
- Fixed content.
- Does not use a database.
- Faster loading.
- Easy to develop.

Example:
- Portfolio Website
- Company Landing Page

Dynamic Website:
- Content changes according to user interaction.
- Uses a database.
- More interactive.
- Requires backend development.

Example:
- Facebook
- Amazon
- Instagram

9. Five Web Browsers and Their Rendering Engines
----------------------------------------------------------

1. Google Chrome
   Rendering Engine: Blink

2. Microsoft Edge
   Rendering Engine: Blink

3. Mozilla Firefox
   Rendering Engine: Gecko

4. Apple Safari
   Rendering Engine: WebKit

5. Opera
   Rendering Engine: Blink

Difference between Rendering Engines:

Blink:
- Fast rendering engine.
- Used in Chrome, Edge, and Opera.

Gecko:
- Used by Firefox.
- Focuses on web standards and flexibility.

WebKit:
- Used by Safari.
- Optimized for Apple devices.

10. Basic Web Architecture Diagram
----------------------------------------------------------

                User
                  |
                  V
          +----------------+
          |    Browser     |
          +----------------+
                  |
             HTTP Request
                  |
                  V
          +----------------+
          |   Web Server   |
          +----------------+
                  |
          Business Logic
                  |
                  V
          +----------------+
          |      APIs      |
          +----------------+
                  |
                  V

                  |

6. The browser displays the webpage.
